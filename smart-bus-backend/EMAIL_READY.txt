🎯 HOW TO USE (3 Simple Steps):

┌────────────────────────────────────────────────────────────┐
│ STEP 1: Configure Your Gmail                              │
└────────────────────────────────────────────────────────────┘

1. Go to: https://myaccount.google.com/apppasswords
2. Enable 2-Factor Authentication (if not already enabled)
3. Create an App Password:
   - Select: Mail
   - Device: Other (Custom name) → "SmartBus"
   - Click Generate
   - Copy the 16-character password

4. Edit .env file and update:
   SMTP_USER=youremail@gmail.com
   SMTP_PASS=xxxx-xxxx-xxxx-xxxx  ← Paste app password here

┌────────────────────────────────────────────────────────────┐
│ STEP 2: Test the Email System                             │
└────────────────────────────────────────────────────────────┘

1. Edit: utils/test-email.js
   Change line 13:
   userEmail: 'your-real-email@gmail.com',  ← Your email!

2. Run test:
   node utils/test-email.js

3. Check your inbox (and spam folder)
   You should receive 2 beautiful emails:
   ✅ Payment Confirmation
   ✅ Recharge Confirmation

┌────────────────────────────────────────────────────────────┐
│ STEP 3: Make a Real Payment                               │
└────────────────────────────────────────────────────────────┘

1. Start your server:
   npm run dev

2. Make a payment via API or frontend
   Email will be sent automatically!

3. Check server console:
   📧 Sending payment confirmation email to: user@example.com
   ✅ Email sent successfully! Message ID: <...>

🔧 Technical Details:

  Emails are sent when:
  • User makes a payment (POST /api/cards/pay)
  • User recharges card (POST /api/cards/recharge)

  Email includes:
  • Card UID
  • Amount (in T-Pay)
  • Balance
  • Date & Time
  • Beautiful HTML design

  Features:
  ✓ Non-blocking (doesn't slow down API)
  ✓ Async (sends in background)
  ✓ Graceful failure (email errors don't break payments)
  ✓ Professional design
  ✓ Plain text fallback
